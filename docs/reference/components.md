# Components

All the components in our micro:bit kits, grouped by where they are and what they do. Each one links to its page.

| Component | Type | What it does | Possible uses |
| --- | --- | --- | --- |
| [Display](../microbit/display.md) | Output | A 5 × 5 grid of LEDs that shows text, numbers and images | Messages, scores, icons, animations |
| [Buttons](../microbit/buttons.md) | Input | Two push buttons, A and B | Game controls, timers, menus |
| [Accelerometer](../microbit/accelerometer.md) | Input | Measures movement and tilt, and detects gestures such as shaking | Step counters, dice, tilt games |
| [Temperature](../microbit/temperature.md) | Input | Measures the approximate air temperature | Weather stations, overheating alerts |
| [Light Sensor](../microbit/light.md) | Input | Measures light levels using the display's LEDs | Night lights, light-activated alarms |
| [Compass](../microbit/compass.md) | Input | Measures magnetic fields to find direction | Navigation, treasure hunts, magnet switches |
| [Touch](../microbit/touch.md) | Input | Senses touch on the logo and pins 0, 1 and 2 | Extra buttons, musical instruments |
| [Speaker](../microbit/sound.md) | Output | Plays tunes, tones and speech | Sound effects, alarms, talking projects |
| [Microphone](../microbit/sound.md#microphonecurrent_event) | Input | Measures how loud it is | Sound-activated lights, noise meters |
| [Radio](../microbit/radio.md) | Input and output | Sends and receives messages between micro:bits | Multiplayer games, remote controls |

## micro:bit vs smartphones

### Comparison

| Feature | micro:bit | Smartphone |
| --- | --- | --- |
| Processing power | A simple 64 MHz processor | Multi-core processors running at over 2 GHz |
| Memory and storage | 512 KB flash, 128 KB RAM | Many GB of RAM and 64 GB or more of storage |
| Display | 5 × 5 red LED grid | High-resolution, full-colour touchscreen |
| Input | Two buttons, touch logo and pins, sensors | Multi-touch screen, cameras, microphones, many sensors |
| Audio | Small built-in speaker for tones and simple speech | High-quality stereo audio, music and phone calls |
| Connectivity | Bluetooth and micro:bit radio | Wi-Fi, Bluetooth, 4G/5G, NFC, GPS |
| Camera | None | Front and rear cameras with video recording |
| Software | Small programs written in MicroPython or MakeCode | Complex apps, games and productivity tools |
| Power | USB or a small battery pack | Large rechargeable battery with power management |
| Sensors | Accelerometer, compass, light, temperature, microphone | GPS, gyroscope, barometer, proximity, fingerprint and more |
| Internet | None | Full internet access |

### Strengths and weaknesses

| Device | Strengths | Weaknesses |
| --- | --- | --- |
| micro:bit | - easy for beginners to program<br>- cheap and tough<br>- great for learning coding and electronics<br>- built-in sensors for hands-on projects<br>- easy to connect to other electronics | - very limited processing power and memory<br>- tiny single-colour display<br>- no internet access<br>- limited ways to input information<br>- short battery life on small batteries |
| Smartphone | - powerful processor and lots of memory<br>- high-resolution colour touchscreen<br>- full internet access and apps<br>- many advanced sensors<br>- all-day battery life | - expensive to buy and replace<br>- hard for beginners to program<br>- not designed for connecting electronics<br>- more fragile<br>- apps can distract from learning |
